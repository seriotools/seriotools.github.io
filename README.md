# seriotools.github.io

Built with **Astro 7.3** on **Node 26**, using **TypeScript 6.0.3** (the version
Astro 7.3.x correlates with).

## Commands

```bash
npm run dev        # dev server      -> http://localhost:4321
npm run build      # production build -> dist/
npm run preview    # preview the build
npm run check      # astro check (type-check .astro files)
```

See [`.devcontainer/README.md`](.devcontainer/README.md) for toolchain
correlation notes (Node 26 image line, TypeScript 6 vs 7, `allowScripts`).
